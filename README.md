## Overview

AI Content Contest Radar 2026 is a static HTML application that gathers AI contest listings into a single searchable interface. It covers both domestic and international opportunities, making it easier to review current contests without checking numerous websites individually.

Designed for quick evaluation and ongoing personal organization, the app lets you refine listings by region, status, deadline, and category. Each listing can also include its theme, requested submission content, recommendation score, and schedule progress to support faster comparisons.

---

## What It Provides

- Combines domestic and international AI contest listings in one web interface
- Removes expired contests from the active view automatically
- Narrows results using region, status, deadline, and category filters
- Includes text search and sorting tools for finding relevant opportunities
- Saves contest information as CSV or JSON exports
- Presents contest themes, submission requirements, recommendation scores, and schedule progress
- Keeps favorites and user notes in browser localStorage
- Works as a static HTML app without requiring server-side setup

## Using the App

Search across contest names, themes, and other related listing information from the search field. Filters can be combined to limit the results to the region, status, deadline range, or category that matters to you.

A common workflow is:

1. Start the application in a browser.
2. Enter a contest name or subject in the search field.
3. Use the available filters to reduce the result set.
4. Mark promising contests as favorites.
5. Attach personal notes for later comparison.
6. Export the current contest data as CSV or JSON when an offline copy is useful.

## Data and Customization

The application manages most user-specific settings through browser localStorage. Favorites and notes remain on the device and browser profile used to access the app.

To modify the listing source or how contests are displayed, update the static HTML and associated data files in the repository. Since the project is a static web app, these changes are made in the project files rather than through an administrative dashboard.
